# Car Price Prediction

ML-пайплайн для предсказания стоимости автомобилей на основе реальных данных. Проект реализует полный цикл от предобработки сырых данных до обучения модели с логированием экспериментов через MLflow и оркестрацией через Apache Airflow.

## Описание

Модель предсказывает цену автомобиля по его характеристикам: марке, модели, году выпуска, пробегу, двигателю, коробке передач, цвету и истории эксплуатации. В основе — градиентный бустинг CatBoost с оптимизацией гиперпараметров через Optuna.

Датасет: ~188 000 записей о продаже автомобилей.

## Стек

| Категория | Инструмент |
|---|---|
| Модель | CatBoost |
| Гиперпараметры | Optuna + Hyperband |
| Трекинг экспериментов | MLflow |
| Оркестрация | Apache Airflow |
| Препроцессинг | Pandas, NumPy, Scikit-learn |

## Структура проекта

## Пайплайн

```
CSV-данные
    ↓
Preprocessing.make_preprocessing()
├── Парсинг движка (мощность, объём, цилиндры, тип топлива)
├── Парсинг коробки передач (тип, число передач)
├── Нормализация цветов (12 стандартных категорий)
└── Заполнение пропусков (медиана по марке → модели → глобальная)
    ↓
Разбивка: train 70% / test 30%  (+ val 20% от train)
    ↓
Modeling.find_hyperparams()  — поиск гиперпараметров через Optuna
    ↓
Modeling.model_fit_predict()  — обучение и оценка модели
    ↓
Метрики: MAE, MSE, RMSE  +  логирование в MLflow
```

## Установка

```bash
git clone <repo-url>
cd car_price
pip install catboost scikit-learn optuna mlflow pandas numpy apache-airflow
```

## Использование

### Запуск через main.py

Откройте [main.py](main.py), укажите путь к CSV-файлу в функции `pulling_data()`, затем:

```bash
python main.py
```

### Запуск ноутбука

```bash
jupyter notebook model_car_price.ipynb
```

### Запуск Airflow DAG

```bash
airflow db init
airflow scheduler &
airflow webserver &
```

DAG `take_data` будет запускаться ежедневно по расписанию `0 0 * * *`.

## Признаки модели

| Признак | Описание |
|---|---|
| `brand` | Марка автомобиля |
| `model` | Модель |
| `model_year` | Год выпуска |
| `milage` | Пробег (миль) |
| `fuel_type` | Тип топлива |
| `engine_hp` | Мощность двигателя (л.с.) |
| `engine_liters` | Объём двигателя (л) |
| `engine_cylinders` | Число цилиндров |
| `transmission_auto` | Автоматическая КПП (0/1) |
| `transmission_gears` | Число передач |
| `ext_col` | Цвет кузова |
| `int_col` | Цвет салона |
| `accident` | Были ли аварии (0/1) |
| `clean_title` | Чистый титул (0/1) |

**Целевая переменная:** `price`

## Метрики

Модель оценивается на тестовой выборке:

- **MAE** — средняя абсолютная ошибка
- **MSE** — среднеквадратичная ошибка
- **RMSE** — корень из MSE

Все эксперименты логируются в MLflow: гиперпараметры, метрики, артефакты.
